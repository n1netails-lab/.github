# .github

Organization-level defaults for **[n1netails-lab](https://github.com/n1netails-lab)**.

GitHub reads community health files from this repository and applies them to every repo in the org that does not define its own.

## Contents

| Path | Applies to | Purpose |
| --- | --- | --- |
| [`profile/README.md`](profile/README.md) | Org profile page | Public description of what N1neTails Lab is and is not |
| [`SECURITY.md`](SECURITY.md) | All org repos without their own | Disclosure policy — where to report, how findings are handled |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | All org repos without their own | What contributions belong here vs. upstream |

## Important

Repositories in this org are **forks of real open source projects**, used as subjects for application security analysis. They are not intentionally vulnerable applications, and their presence here is not a claim that the upstream project is insecure.

Community health files here are the org's own — they do **not** override a fork's upstream `LICENSE`, `NOTICE`, or attribution, and they should not be copied into forks in a way that displaces upstream's own policies.

## Editing

Changes to `profile/README.md` are live on the org profile page as soon as they are merged to `main`. Everything else takes effect for any repo that lacks its own copy of the file.
