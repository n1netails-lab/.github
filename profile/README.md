# N1neTails Lab

Welcome to **N1neTails Lab** 🦊

N1neTails Lab is a centralized collection of intentionally vulnerable applications and security labs designed for learning, security research, and evaluating application security tools.

The goal of this organization is to provide hands-on environments for developers, security engineers, and AppSec teams to practice identifying, understanding, and remediating common security vulnerabilities.

---

## 🎯 Purpose

N1neTails Lab provides vulnerable applications that can be used to:

- Learn secure coding practices
- Practice vulnerability identification and remediation
- Evaluate Static Application Security Testing (SAST) tools
- Test GitHub Advanced Security features
- Experiment with CodeQL queries
- Understand common application security weaknesses
- Build AppSec automation workflows

---

## 🔐 Security Labs

The organization contains intentionally vulnerable applications covering areas such as:

- Web Application Security
- API Security
- Software Supply Chain Security
- Container Security
- Cloud Security
- Infrastructure as Code (IaC)
- Secure Development Practices

Examples of vulnerabilities include:

- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Path Traversal
- Insecure Deserialization
- Hardcoded Secrets
- Authentication Issues
- Authorization Issues
- Dependency Vulnerabilities
- Memory Safety Issues
